# 小红书图文排版设计

## 目标

把现有“小红书正文 + 单张横图”升级为可直接用于半自动发布的图文包：正文可复制，首图、要点卡和尾图可预览、逐张保存或打包下载。

## 产品边界

- 保留人工登录和最终发布，不保存小红书账号密码或 Cookie。
- Replicate 只生成与主题相关的首图背景，不负责绘制中文。
- 本期不增加复杂模板市场，只提供三套稳定主题并自动选择默认主题。
- 小红书图片统一为 1080 x 1440（3:4）JPEG。
- 正文中的每个主要编号要点对应一张内容卡，最多五张；另加首图和尾图。

## 架构

1. `xiaohongshu_content` Skill 继续负责标题、正文和标签。
2. 新增 `xiaohongshu_layout` Skill，定义拆卡、视觉层级、主题选择和发布包规则。
3. `xhs_layout.py` 解析 Markdown 发布包，输出结构化正文并使用 Pillow 渲染卡片。
4. 任务结果新增 `xhs_layout`，包含主题、发布正文、卡片路径和 ZIP 路径。
5. Web 页面优先展示图文卡片画廊，并提供复制正文、逐张保存、打包下载和打开小红书创作平台。

## 数据契约

```json
{
  "xhs_layout": {
    "theme": "fresh-green",
    "title": "秋天养元气，先做这4件小事",
    "body": "...",
    "tags": ["#职场女性", "#健康养生"],
    "publish_text": "...",
    "cards": [
      {"index": 1, "kind": "cover", "path": "output/.../01-cover.jpg", "title": "..."}
    ],
    "zip_path": "output/.../xiaohongshu-package.zip"
  }
}
```

## 交互

- 小红书任务生成内容后可单独执行“生成图文排版”。
- 一键生成在小红书渠道中依次执行素材、内容、封面和图文排版。
- 缺少小红书正文时拦截排版步骤并给出中文提示。
- 预览区展示 3:4 卡片网格；发布操作区只复制可发布正文，不包含“封面图组”说明。

## 错误处理

- 找不到中文字体时尝试项目和系统候选字体；全部不可用时抛出明确错误。
- 首图背景不存在时使用主题自带背景，仍能完成排版。
- 正文没有编号要点时按有内容的段落生成最多三张内容卡。
- 单卡文本过长时截断并提示用户回正文查看，避免字号无限缩小。

## 验收标准

- 小红书 Replicate 请求使用 3:4，输出文件为 1080 x 1440。
- 具有四个正文要点时生成首图、四张要点卡和尾图，共六张。
- 所有图片能在页面完整预览且不变形。
- ZIP 包含全部卡片和 `发布文案.txt`。
- 复制发布包不包含“封面图组”说明。
- 公众号现有 16:9 封面和草稿流程不受影响。
