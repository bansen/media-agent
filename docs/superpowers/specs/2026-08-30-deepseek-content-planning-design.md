# DeepSeek 内容策划设计

## 目标

链接内容和普通创作提示词统一先经过 DeepSeek 策划，再生成中文标题、正文和封面。规则模板只负责输入校验，不再决定最终标题和文章结构。

## 数据流

1. WebSearch 或百度收集原始素材并选出最高分素材。
2. DeepSeek 读取用户提示词、渠道、来源标题、链接和素材摘要，返回结构化内容策划。
3. 系统校验策划字段、中文标题、禁用词和标题长度；失败时明确报错并允许重试。
4. 最佳标题写回 `WorkflowResult`，并重建公众号大纲、小红书发布包和封面提示词。
5. DeepSeek 使用同一份策划和项目内 `wechat-write` / 小红书 Skill 生成正文。

## 内容策划契约

```json
{
  "core_topic": "项目真正解决的问题",
  "target_audience": "最匹配的读者",
  "pain_point": "读者当前遇到的具体困难",
  "core_value": "项目提供的具体结果",
  "key_points": ["事实要点1", "事实要点2", "事实要点3"],
  "article_structure": ["开场", "定位", "核心能力", "使用流程", "边界与判断"],
  "cover_concept": "与核心价值直接对应的可视化场景",
  "titles": ["候选标题1", "候选标题2", "候选标题3", "候选标题4", "候选标题5"],
  "selected_title": "最佳中文标题"
}
```

## 标题规则

- 标题必须使用中文表达，可保留必要的产品名、AI、PPT、Agent 等专有名词。
- 标题必须体现具体痛点、能力或结果，不能只写项目名和评测模板。
- 禁止链接、README、仓库路径、项目分享、值不值得试、核心场景、使用门槛等来源或模板话术。
- 公众号标题不超过 34 个字符，小红书标题不超过 20 个字符。
- `selected_title` 必须存在于候选标题中；不满足时拒绝策划结果，不静默回退模板。

## 错误处理

- DeepSeek 返回 Markdown 代码块时提取其中 JSON。
- JSON 缺字段、标题非中文或触发禁用词时抛出中文错误。
- 一键生成在策划失败时停止，不继续生成正文和封面。
- 单独生成素材会调用 DeepSeek 并保存策划；单独生成正文复用已保存策划，不重复调用策划接口。

## 验收标准

- 链接项目的材料步骤至少调用一次 DeepSeek，并展示 LLM 生成的中文标题。
- 一键生成调用两次 DeepSeek：一次策划、一次正文。
- 正文 Prompt 包含结构化策划和项目内内容 Skill。
- 正文一级标题、预览标题和封面主题使用同一个 `selected_title`。
- 旧任务没有 `content_plan` 时，重新生成正文会先自动调用 DeepSeek 补建策划，不再使用模板策划。
